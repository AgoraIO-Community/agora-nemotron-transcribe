# Connectivity-test speech sample

`public/sample.wav` is the first 15 seconds of `OSR_us_000_0010_8k.wav`, from the **Open Speech Repository**, sponsored by Telchemy. It has been resampled from mono 8 kHz PCM to mono 16 kHz PCM.

Source: https://voiptroubleshooter.com/open_speech/american/OSR_us_000_0010_8k.wav

Reuse terms: https://voiptroubleshooter.com/open_speech/about.html — permits copying, modifying and incorporating these recordings into websites and development applications with attribution to “Open Speech Repository”. This attribution applies to the sample audio; it is not relicensed as repository MIT code.

This English recording is used only by `pnpm run smoke:inference`. It is not a Hindi evaluation sample and does not appear as a scored player attempt.

`launch-planning.txt` is an optional original script for recording your own audio; it is not the source of the included sample.
